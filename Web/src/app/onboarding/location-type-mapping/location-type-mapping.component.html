Location Code Mapping

NHSNLink requires your facility's location codes to be translated to HSLOC (Healthcare Service Location Code) values before reporting. Enter your EHR's location identifier system URI and map each local code to its HSLOC equivalent below.

Two normalization operations will be created automatically: a Code Map that translates the codes, followed by a Copy Location that promotes them into Location.type.
