Encounter Type Mapping

Map your EHR's encounter type codes to standard SNOMED CT values so NHSNLink can classify patient encounters correctly.

Two normalization operations will be created: a Code Map translating Encounter.type.coding to SNOMED, and a Conditional Transform that automatically sets Encounter.status to finished when a period end date is present.
